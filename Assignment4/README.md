# How to use this

### Please make the python environment (venv) and install

- torch
- torchvision
- torchaudio
- tdqm
- jupyter (If you are using Jupyter Notebook)

### Files

#### image_gen.py

This file will ask you with the prompt and generate the image out of it. The codes are based from the given Jupyter Notebook.

#### cuda_tester.py

This file is a tester if the CUDA is available or not.
